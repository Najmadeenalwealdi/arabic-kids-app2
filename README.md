# مغامرات الحروف والأرقام

لعبة ويب عربية للأطفال لتعلّم الأرقام من ١ إلى ١٠ والحروف العربية من أ إلى ي.

## التشغيل
1. فك ضغط ملف ZIP.
2. افتح مجلد `arabic_kids_adventure`.
3. افتح `index.html` بمتصفح حديث مثل Chrome أو Edge أو Firefox.
4. اختر مملكة الأرقام أو غابة الحروف أو تحدّي الأبطال.

لا تحتاج اللعبة إلى تثبيت مكتبات أو تشغيل خادم. الصور التوضيحية في هذه النسخة عبارة عن رموز Emoji لتعمل دون تحميل ملفات صور خارجية. خط Cairo يُحمّل من الإنترنت إن كان الاتصال متوفرًا، وإلا يستخدم المتصفح خطًا بديلًا.

## المزايا
- واجهة عربية RTL مناسبة للكمبيوتر والجوال.
- بطاقات للأرقام والحروف مع أمثلة مصوّرة.
- نطق عبر Web Speech API عند دعم المتصفح ووجود صوت عربي على الجهاز.
- اختبار بثلاثة اختيارات.
- حفظ عدد النجوم على نفس الجهاز باستخدام localStorage.
- زر لتشغيل الصوت وإيقافه.

## ملاحظات
- جودة الصوت وتوفر الصوت العربي يعتمدان على نظام التشغيل والمتصفح والأصوات المثبتة. اللعبة لا تتضمن تسجيلات صوتية بشرية مدمجة.
- تقدم النجوم محفوظ محليًا في المتصفح، ولا تتم مزامنته بين الأجهزة.
- هذه نسخة تعليمية أولية قابلة للتطوير؛ لا تجمع بيانات الأطفال ولا تتصل بخادم.
